# 萍萍小助手 Stitch 原型生成包

本目录不是网页源码，而是可以直接复制到 Google Stitch 的生成指令。Stitch 支持自然语言和参考图片生成 UI，因此本包按“小程序端”和“管理后台”拆成两个 Stitch 项目，避免手机与桌面布局互相干扰。

## 推荐使用顺序

### 小程序端

1. 在 Stitch 新建 Mobile 项目。
2. 复制 `01-小程序端-首次生成.txt` 的全部内容生成第一版。
3. 在同一项目的对话中，按顺序复制 `02-小程序端-继续生成.txt` 中的逐屏指令。
4. 每生成一屏，确认视觉语言与首页一致后再继续下一屏。

### 管理后台

1. 在 Stitch 新建 Web/Desktop 项目，不要与小程序放在同一个项目中。
2. 复制 `03-管理后台-首次生成.txt` 的全部内容生成经营看板。
3. 在同一项目的对话中，按顺序复制 `04-管理后台-继续生成.txt` 中的逐屏指令。
4. 最后使用文件末尾的“全局统一修正指令”统一组件与视觉。

## 使用约束

- 所有界面文字使用简体中文。
- 品牌名固定为“萍萍小助手”，示例店铺固定为“萍萍服饰”。
- 架构文案统一使用“自有服务器”或“服务器已同步”，不要出现腾讯云开发、云函数、云数据库。
- 小程序只保留门店现场高频操作；批量维护、权限、审计、导入导出放到管理后台。
- Stitch 生成的是设计原型，不代表已经连接真实 API 或 MySQL。
