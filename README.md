# 萍萍小助手

供单家实体服装店内部使用的微信原生小程序，聚焦商品档案、进货、售出、颜色尺码库存、盘点、操作记录和商品毛利分析。

## 本地运行

1. 打开微信开发者工具。
2. 选择“导入项目”，目录选择本文件夹。
3. 首次预览可使用测试号；正式发布前将 `project.config.json` 中的 `appid` 与 `utils/cloud-config.js` 中的云配置替换为自己的值。
4. 如使用云环境共享，还需按[微信云开发部署说明](docs/guides/微信云开发部署说明.md)配置云函数中的 AppID 占位符。
5. 编译后为全新空库存，可从“库存 → 新建商品”录入店内实际商品。

## 当前数据方式

当前版本使用微信 OpenID 识别店主账号，商品、库存、销售与盈利数据通过云函数同步到云数据库，同时保留本机缓存以保证操作响应。部署步骤见[微信云开发部署说明](docs/guides/微信云开发部署说明.md)。当前同步模型适合同一店主的多设备使用；多人同时编辑前仍建议升级为分集合、事务和角色权限模型。

## 核心流程

- 新建商品：填写名称和分类即可先创建，系统自动生成连续流水编号；商品删除后，排在后面的商品立即向前顺位，编号始终从 `0001` 连续排列。可选填写吊牌或厂家货号。
- 拿货：记录数量、单件拿货价、本次拿货总额和供应商，并自动增加库存；记录页汇总今日及本月拿货成本。
- 售出：记录数量、售价和收款方式，并自动扣减库存。
- 盘点：填写实际库存，系统保留盘点前后差异。
- 查询：支持按名称、系统编号或货号搜索，并按分类筛选。
- 盈利：查看今日、昨日、本月、上月或指定日期的收入、成本、盈利和毛利率，支持补录额外收入或支出，并提供按需展开的趋势、商品表现及收款方式统计。

底部导航为“首页、商品、记一笔、账本、我的”。“商品”中切换服装与化妆品；“记一笔”集中处理拿货、增加库存、卖货和其他收支；“账本”查看盈利及各类记录。
